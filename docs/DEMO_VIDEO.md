# 60–90 second demo video script

**0–10 seconds — Problem**

“Smart contracts can enforce rules, but they cannot normally inspect today’s public web and decide a disputed real-world fact. TruthBond brings evidence-backed disputes on-chain with GenLayer.”

**10–25 seconds — Bonded claim**

“Here is our demo claim: Ethereum’s Dencun upgrade activated on mainnet on March 13, 2024. The creator locked 1 test GEN and defined an objective two-source verification standard.”

**25–40 seconds — Challenge and evidence**

“A second wallet matched the 1 GEN bond and challenged the exact activation date. Both sides added public evidence: an Ethereum Foundation announcement and an independent report.”

**40–60 seconds — Intelligent Contract**

“Resolution happens inside the deployed TruthBond Intelligent Contract—not in the frontend. GenLayer validators independently retrieve the sources, isolate untrusted page content, return structured JSON, and compare the essential verdict through a custom equivalence principle.”

**60–75 seconds — Verdict and settlement**

“The finalized screen shows the real consensus verdict, confidence, source tally, explanation, and on-chain settlement credit. The winner can claim once; duplicate settlement is rejected.”

**75–90 seconds — Proof**

“The public app, source repository, contract address, and every demo transaction are linked here. TruthBond: put evidence behind the claim—and value behind the outcome.”
